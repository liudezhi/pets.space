# pets.space · 栖光谷

一座为离世猫狗建造的写实 3D 纪念花园。任何人都能入园漫游，也能为宠物送一束免费花。主人凭邀请码付费建园，保存照片与回忆。项目以一百年为存续目标。

## 运行纪念花园

建议使用 Node.js 24 LTS，最低支持 22.13。在仓库根目录执行以下命令。

```sh
npm ci
npm run dev
```

打开终端给出的地址即可看景。三个地点可以直达，纪念册可在纯图片模式下阅读。点「进入 3D 漫游」会按需加载共用地形；桌面用方向键或 WASD 行走，拖动环顾，Q/E 转向，Esc 返回。手机用方向盘行走、拖动看景。沿小路从西南入口经过纪念石，穿过拱桥，即可到达许愿树。

### 建一座测试花园

1. 点击「我的花园」，输入服务启动终端显示的测试邀请码，保存单独生成的园主恢复码。该邀请码用于本轮免费测试。换设备时打开同一台服务器的网站，用恢复码找回档案；每次成功恢复都会产生一个新的恢复码。
2. 在河湾或桦坡选址，填名字、照片与回忆，预览后保存。新建花园仅园主可见。照片在浏览器中缩放并转换为最长边 1280 像素的 WebP，当前保存的是纪念展示图。请自行保留原始照片。
3. 选择「公开花园」后即可复制探访链接。亲友无需邀请码和建园账号；可以阅读、送免费雏菊，也能走到 3D 石前看照片。可随时转为私密或关闭收花。要先体验访客流程，可以在「纪念册」中探访示例犬麦子。

### 启动、测试与保存

| 用途 | 命令或配置 |
| --- | --- |
| 接口与重启回归 | `npm test` |
| 运行构建版本 | `npm run build` 后执行 `npm start`，默认仅监听本机的 4173 端口 |
| 两台设备访问 | 在受信任的局域网里将 `HOST` 设为 `0.0.0.0` 启动构建版本，双方访问同一台电脑的局域网 IP 和端口。使用本机回环地址生成的链接只适用于本机。 |
| 持久数据 | SQLite 默认位于仓库同级的 `.pets-space-data/<项目目录名>/`，可通过 `PETS_DATA_DIR` 指向项目以外的固定目录。停止服务后备份整个数据目录；换机器运行服务器时需连同此目录一起迁移。 |
| 测试邀请码 | 直接启动会产生并显示本次进程的测试邀请码。可在服务端设置 `PETS_INVITE_CODE`；重启不会使已有档案和有效恢复码失效。 |

当前分享功能依赖这台服务器持续运行。单独打开之前的离线 HTML 可体验风景；本轮建园、照片和送花记录由服务端保存。真实支付、原图归档及百年运营机制属于后续阶段。
