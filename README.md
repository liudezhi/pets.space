# pets.space · 栖光谷

一座为离世猫狗留下照片、故事和风景的 3D 山谷花园。访客可免费逛园、读公开纪念册、送一束雏菊；主人通过邀请码开通资格，为宠物选址、留存原件、接待亲友。园区以一百年为存续目标。

## 本机启动

在仓库根目录使用 Node.js 24 LTS（最低 22.13）与 npm。

```sh
npm ci
npm run dev
```

打开终端显示的地址。从「纪念册」探访示例犬麦子。想散步时点「进入 3D 漫游」，以 WASD 或方向键行走、拖动环顾，Q/E 转向，Esc 退出。手机可按住方向键并拖动看景。图片导览和纪念册也适用于没有 WebGL 的设备。

要用接近景观参考图的光线看实景，在「时光与天气」选「晴秋傍晚」，再点「查看 3D 风景」。自动画质在驻足时恢复清晰度，也可手选精细或轻量。点「跟随园区」可恢复园区自己的时间、季节和天气。

游园默认使用「自动」。沿路转头或行走时，浏览器根据实际绘制速度调整水面倒影、远处草木和画布大小。停下看照片后会恢复设备对应的高清画幅。较慢设备可以在「时光与天气 → 画面精度」选「轻量」。勾选「减少动态效果」后，驻足时会减少重绘，按方向键就会马上更新画面。

## 制作可带走的体验版本

下载完整验收包后，按包内《从这里开始》打开网站。包中含已构建的网页、Node 服务、源码和验收手册。独立的免安装 HTML 适合先看景，打开后可在同一河湾行走并切换四季与天气。

开发者可在已经执行 `npm ci` 和 `npm run build` 的仓库重建两个文件。完整包使用 Python 3.9 及以上版本，输出文件放在项目外。

```sh
python3 scripts/package_local.py ../栖光谷-完整验收版.zip
node scripts/package-walkthrough.mjs ../栖光谷-免安装游览.html
```

## 第一次建园

1. 默认付款模式为本地沙盒。服务启动时会打印邀请码**文件路径**。在自己管理的机器上打开该文件，默认位置为仓库同级的 `.pets-space-data/<项目目录名>/sandbox-invite.txt`。设置了 `PETS_DATA_DIR` 时位于该数据目录内；设置了 `PETS_INVITE_CODE` 时使用所配置的值。
2. 进入「我的花园」，填写测试邀请码，核对基础建园示例价 ¥39，点「确认模拟付款」。本地沙盒不会扣款。单独保管随后显示的**园主恢复码**，换设备登录需要它。
3. 点「新建纪念花园」，在河湾或桦坡选址，上传照片、填写名字与回忆，再点「私密预览」和「保存私密花园」。可同时将照片原件存入私密相册。主动公开后可复制分享链接，亲友无需建园资格即可免费献花。
4. 想把照片和回忆带回家时，打开这座花园的「导出离线纪念册」。亲友看到的照片和园主导出的原件遵循不同的访问权限。

## 换设备与持续开发

| 任务 | 做法 |
| --- | --- |
| 运行自动化测试 | `npm test` |
| 启动构建版 | `npm run build`，再执行 `npm start`；默认监听 `127.0.0.1:4173` |
| 在同一受信局域网内试用 | 在服务端执行 `HOST=0.0.0.0 npm start`，两台设备访问同一台服务器的局域网地址。用新设备上的独立浏览器验证分享或恢复。 |
| 接手续写代码 | 获取最新 `main`，先读[开发记录](docs/开发记录.md)。账号、照片和订单保存在服务端 SQLite，迁移服务器时须单独备份及恢复。 |
| 本机逐项体验 | [验收手册](docs/验收手册.md)含园区散步、天气、亲友送礼、托管付款边界、家庭移交和离线阅读。 |
| 保管数据、配置支付、交接运营 | [运行与百年保存](docs/运行与百年保存.md)含可选 Stripe 配置、快照与恢复步骤、经营责任。 |

当前交付已在本地服务、桌面 Chromium 和模拟移动视口进行验收。外部 Stripe 商户、正式域名、移动真机与跨机构百年接续仍需实际运营方验证。[浏览器验收记录](design-qa.md)
