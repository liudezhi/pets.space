## 2026-11-19 · 游园流畅度

- **访客体验**　自动画质根据连续移动的帧耗分档，可逐级恢复。停步恢复高清画幅和精细水面。选中「减少动态效果」后，驻足减少重绘；操作方向键、弹出新照片、撤下公开碑或切换气候时会重新绘制。
- **渲染改动**　陆地、河床、草木和步道碎石按视野剔除；远距离使用轮廓一致的简化几何；公开碑体、相框和步道灯按材质合并绘制。水面每像素取样随画质从六次切到四次或一次，近看仍有精细倒影。弱设备行走时使用较小的阴影滤波核。同一设备驻足可回到原有照片清晰度。
- **交接与复验**　从干净检出构建应用和两个交付包，38 项自动测试通过。解压完整包后 40 条园主与访客浏览器断言通过，涵盖私密访问、照片、纪念册和匿名献花。免安装包在 390 × 844 模拟触屏、完全断网的浏览器中通过四机位探访、行走、取消触控与驻足恢复检查。固定路线基准在独立 Chromium 中回读已绘制的像素，分别记录内部渲染尺寸、真实耗时和位移。[机位与性能记录](../design-qa.md)

## 2026-11-19 · 河湾实景美术修订

- **石前停留**　主人站在照片前，可以同时看见嵌框石灰岩、岸边碎石以及身后的单孔石桥。手机竖屏单独校正照片取景。许愿树的低枝、布带和根脚指向来路，山庭用矮石墙和长椅围出可以看河的坐处。
- **远近与光线**　前景细草、种穗、花、小石和近岸芦苇按地形疏密分布。桥下可见浅水河床和卵石后的细流。河面取色与天空、远山相联，日照投射树影；冬季草量减少，雨天石面变湿。自动画质在驻足时恢复清晰度。「晴秋傍晚」可以重访同一种光线。
- **如何比较**　取上一版 `07f90c3` 的相机位置、朝向与视角，在相同的秋日、天气和分辨率分别实拍新旧两版。另拍新版正式落脚点，分别留存。测试入口为 `scripts/capture-scenes.py`。[实景与验收记录](../design-qa.md)
- **步道复查**　步道中心线 801 个采样点和桥面 1,100 个采样点均可走通。桥外河面 3,318 个取样点均受到阻挡。按 0.25 米网格从入口出发，可以到达四处地标、两处纪念石落点和六个公开墓位入口。
- **交付复查**　干净副本完成锁定安装、生产构建和 34 项自动测试。解压完整验收包启动服务，40 条园主与访客浏览器断言通过。离线 HTML 二次构建逐字节相同。浏览器在离线模式读入实际交付字节，核对四处落脚点、春晨晴、秋暮雨、冬夜雪和画质切换；禁用 WebGL 后仍能看导览和麦子的纪念册。

## 2026-11-19 · 开放园区、家庭档案与结算

- **为何来逛**　从西南桦坡散步时可以看到别家愿意公开的纪念石，近身读名字，点开照片和主人的话，安静送一束免费的雏菊。每区六个固定位置。春晨、秋日雨后和冬季星夜可以重复从同一机位观察；把时段恢复为园区时间，又会与其他访客看到同一时节。这里验证了可以回访的功能，真实家庭的回访意愿仍需观察。
- **为何选择留下**　园主先看园址、照片与私密预览，再决定公开。首次建园可同时保存原件，家庭相册允许逐张授权；原件、寄语、礼物历史和园址的固定风景均可离线带走。家庭可借助恢复码换设备，也可把单座花园明确移交给指定家人。
- **开通与赠礼**　免费献花向匿名访客开放。凭邀请码开通园主资格，礼物与庭院另行下单。交付沙盒及可配置的 Stripe 托管支付，后台可批量签发一次性邀请码。模拟订单/事件验证过重复通知、失败恢复和人工复核；正式商户尚未联调。
- **实测**　用独立 Chromium 会话和临时 SQLite 跑通 40 次建园/探访/档案流程断言及 6 次手机视口天气检查。种入七个虚构家庭的公开园，分别以桌面步行、指向碑面和触屏直达核对打开的宠物身份。隐私撤回后再次激活旧碑不能读取档案。离线 HTML 提取的原图与测试上传的字节相同。在线快照恢复后核对到 5 座花园、4 次免费献花、6 条寄语、2 张归档原图、12 笔订单和 4 条庭院成员关系。[浏览器证据](../design-qa.md)
- **交接**　接口、景观、支付、保存与运营的责任写入架构记录，备份工具提供校验清单。恢复演练、退款核对、正式定价与百年运营的维护人由实际运营方接手。[运行与百年保存](运行与百年保存.md)

从 Git 暂存区导出干净副本，Node 24.22.1 按锁文件安装，执行 34 项自动测试，全部通过、无跳过，随后生产构建成功。完整 ZIP 在另一空目录解压、直接运行内置服务，再次通过 40 条浏览器断言。免安装游览 HTML 在干净副本重建后与交付文件逐字节相同。断网桌面/触屏模拟共 21 项检查通过，包含四处机位与时光天气；无 WebGL 时仍可看图和麦子的示例纪念册。云浏览器通过本机文件选择器读取实际 HTML 字节，并以本地 Blob 打开。Zip 中包含源代码、许可与运行说明；家庭数据、密钥和测试订单单独保存。

## 2026-11-19 · 建园、探访与免费献花

- **交付**　河湾和桦坡都可选址；预览后私密保存照片与回忆。公开详情、照片、公共目录和收花开关执行同一套授权规则。档案按稳定编号分享，3D 石前呈现宠物照片、名字和已送到的花。
- **账号与数据**　测试邀请码建立独立园主身份；跨设备使用一次性恢复码，恢复成功后换发新码。浏览器以展示尺寸重新编码照片；服务端使用本地 SQLite 同步保存档案与送花记录。测试开通不产生交易。
- **验收**　在 Chromium 156 的桌面与触屏模拟中，用独立浏览器会话执行 31 条断言。验证匿名档案与照片在私密、公开、撤回三个状态的访问结果，实际献花后从园主会话看到计数，进入 WebGL 看到上传的测试照片和花束，再从新会话恢复私密花园。未进行真机或公开部署测试。
- **回归**　运行 `npm test` 复查权限、恢复码、重启持久化、图片处理、示例档案，以及献花和建园的并发重试。测试使用临时目录与独立进程，重启后复用原测试数据库。

## 2026-11-19 · 首个可步行河湾

- **设计与交付**　结合对河湾概念图的正面反馈，首版沿用「石前看水」取景。保留高清图片导览，新增按需加载的连续 3D 路线、地图与轻量纪念册。地图的约 150 米是设计目标，本次紧凑地形从入口经桥至树下的样板路线约 80 米。
- **验证**　使用 Node 24 从干净副本执行锁定安装、生产构建与资源检查。WebGL 2 实际浏览、键盘行走、地标切换、退出和无 WebGL 回退经过 Chromium 检查。沿路线对地形取样 501 点验证通行性，桥外河面受阻。详见[验收与实景截图](../design-qa.md)。
- **维护交接**　纪念册使用生成的虚构金毛犬「麦子」照片，三个地标共享同一场景。当前只验证首段体验，后续继续制作石面细节、光影及天气。Vite 提示延迟加载的 3D 包超过默认大小阈值，构建通过。
