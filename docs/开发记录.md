# 开发记录

## 当前交接

河湾第一版可以运行。按 [README](../README.md) 启动后，从石前进入 3D，或在地图中直达入口和许愿树。下次从一部真实手机的石前取景开始，记录加载耗时、步行帧率与宠物照片的可读性，再确定写实材质的精度。

## 2026-11-19 · 首个可步行河湾

- **设计与交付**　结合对河湾概念图的正面反馈，首版沿用「石前看水」取景。保留高清图片导览，新增按需加载的连续 3D 路线、地图与轻量纪念册。地图的约 150 米是设计目标，本次紧凑地形从入口经桥至树下的样板路线约 80 米。
- **验证**　使用 Node 24 从干净副本执行锁定安装、生产构建与资源检查。WebGL 2 实际浏览、键盘行走、地标切换、退出和无 WebGL 回退经过 Chromium 检查。沿路线对地形取样 501 点验证通行性，桥外河面受阻。详见[验收与实景截图](../design-qa.md)。
- **维护交接**　纪念册使用生成的虚构金毛犬「麦子」照片，三个地标共享同一场景。当前只验证首段体验，后续继续制作石面细节、光影及天气。Vite 提示延迟加载的 3D 包超过默认大小阈值，构建通过。

## 2026-11-19 · 河湾场景的第一组概念图

- **交付**　绘制北向总图，生成入口望树、石前看水、树下回望三幅概念图。后两个机位均以入口图作为视觉参考。
- **复查**　核对总图的北向、流向与三个视线方向；解码检查三份 WebP，并检查仓库文档链接和 SVG 引用。三幅图均为 1672 × 941。
- **待实测**　按真实地形复核桥的位置和日照，完成可步行视角、手机取景与帧率实测。晴晨、雨后落日和雪夜对照留待固定机位后制作。

## 新条目的写法

按日期倒序追加。写清本次交付与关联提交或合并请求、实际验证环境和步骤、通过或失败结果、未验证项，以及下一位接手者的首个动作。用户体验测试保留经同意的匿名结论。同步更新「当前交接」，让新电脑上的维护者只需读一段就能开工。
